# AI 서비스 노선도

상태: 플레이 가능

- 주차: Week 1
- 원형: 미니 메트로 풍 노선도 퍼즐 (턴제, 시간 제한 없음)
- Quick Check: W1-1, W1-2, W1-3, W1-4, W1-5

## 스테이지

| # | 제목 | 플레이 | Quick Check |
|---|---|---|---|
| 1 | 질문 승객의 여정 | 역을 차례로 눌러 브라우저 → DNS → 인터넷 → Gateway·LB → API 서버 → GPU 노선을 잇는다. 미끼 역(브라우저 속 AI, GPU 전용 회선) 있음. 완성하면 요청·응답 열차가 왕복한다 | W1-5 |
| 2 | 빠른 노선, 가까운 역 | 서울선(100Mbps, RTT 5ms) vs 태평양선(1Gbps, RTT 150ms). 시간 ≈ 왕복 × RTT + 크기 ÷ 대역폭. 챗봇·자동완성은 서울선, 모델·영상 파일은 태평양선 | W1-1 |
| 3 | 누가 서버일까 | 장면 5개에서 장비마다 클라이언트/서버/둘 다를 붙인다 (FastAPI 노트북, API 서버, IoT 카메라, 웹 서버 → DB) | W1-3 |
| 4 | Edge 역 세우기 | AI CCTV 100대의 일 7가지를 Edge/Cloud에 끌어다 놓는다 | W1-4 |
| 5 | 클라우드 노선 운영 | 일주일 수요(시험 전날 920)에 대해 서버를 직접 사서 고정 vs 클라우드로 날마다 조절. 비용·놓친 요청 비교 | W1-2 |

각 스테이지 끝에 Quick Check 정리 질문이 나온다. 틀리면 신뢰도 −1 (5칸).

## 조작

- 클릭, 일 카드는 끌어다 놓기(눌러 고른 뒤 역 클릭도 가능)
- `Enter` 확인 / 하루 운영, `1`~`3` 퀴즈 보기

## 단순화

- 노선 시간 계산은 RTT와 전송 시간만 센다 (TCP 연결 준비, 슬로 스타트 등은 생략).
- 수요는 미리 보여 준다. 실제로는 예측해야 한다.
