# 택배 발송 사무소

상태: 플레이 가능

- 주차: Week 3
- 원형: 파파스 피자리아 + 접시돌리기 (여유 있는 실시간)
- Quick Check: W3-7 (중복 ACK·빠른 재전송), W3-10 (RTT부터 재기), W3-6 (흐름 제어)

## 비유

택배 = 세그먼트, 영수증 = ACK, 발송 장부 = 송신 윈도우, 모래시계 = RTO 타이머, 안개 = 네트워크(분실이 보이지 않음), 수신 창고 = 수신 버퍼.

## 핵심 플레이

나는 송신자. 택배를 발송하고, 영수증을 눌러 처리하고, 모래시계를 지켜본다.

- 영수증 한 장이 그 번호 앞의 택배를 한꺼번에 확인한다 (누적 ACK)
- 중복 영수증 3장(같은 번호가 3번 더) → 그 택배를 바로 재발송 (빠른 재전송)
- 모래시계가 다 되면 재발송 (타임아웃). 실제 TCP처럼 타이머는 맨 앞 미확인 택배 하나에서만 흐른다
- 근거 없는 재발송은 헛발송

시간은 흐르지만 넉넉하다(RTT 6초 안팎, 모래시계 15~20초). 정지·0.5×·1×·2× 속도 조절, 처음 겪는 사건(타임아웃, 중복 영수증 3장, 창고 넘침, 노선 변경)에서는 자동으로 멈춘다.

## 스테이지

1. 하나 보내고 기다리기: Stop-and-Wait, RTT 측정 (튜토리얼)
2. 장부 4칸: 슬라이딩 윈도우, 영수증 분실에도 누적 ACK가 버틴다
3. 분실 사고: 중복 영수증 3장(같은 번호가 3번 더) → 빠른 재전송
4. 모래시계 고르기: 국내 → 해외 노선, RTO 6/13/24초 선택
5. 수신 창고가 가득: 영수증의 빈 칸(rwnd) 지키기

## 무한 모드: 무한 근무

- 스테이지 목록 맨 끝의 ∞ 버튼, 또는 허브의 "∞ 무한 모드" 탭에서 바로 시작.
- 근무마다 무작위: 택배 수(9개부터 늘어남), 장부 칸 수, 왕복 시간, 분실(근무가 거듭될수록 확률 증가)과 영수증 분실. 2번째 근무부터 모래시계 길이 고르기, 3번째부터 중간 노선 변경, 4번째부터 작은 수신 창고(rwnd)가 섞인다.
- 신뢰도와 점수가 다음 근무로 이어진다. 근무를 마칠 때마다 보너스 150 × 근무 번호.
- 신뢰도 5칸이 바닥나면 끝. ★는 근무 1/4/8번 완료에서.
