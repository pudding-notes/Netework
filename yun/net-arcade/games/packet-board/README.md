# 패킷 여행 보드게임

상태: 플레이 가능

- 주차: Week 2
- 원형: 말판 보드게임 (주사위, 관문 칸, 이벤트 칸), 턴제
- Quick Check: W2-3, W2-4, W2-5, W2-6

## 비유

내 말 = 패킷(겹겹이 싼 소포). 안쪽부터 데이터 → TCP 봉투(포트: 그 집의 어느 방) → IP 봉투(IP: 최종 목적지 집, TTL) → 이더넷 봉투(MAC: 바로 다음 장비). 주소는 스티커 카드로 붙인다.

## 핵심 플레이

주사위를 굴려 28칸 원형 말판을 한 바퀴 돈다.

- 관문 칸(장비): 주사위 눈이 남아도 멈춘다. 세 종류
  - 봉투 고치기: 칸을 누르고 스티커를 골라 붙인 뒤 봉인. 함정 스티커가 섞여 있다
  - 질문: 갈림길(같은 동네?), 스위치·라우터가 보는 주소 등
  - 포장 순서: TCP → IP → 이더넷
- 이벤트 칸: O/X 퀴즈(맞히면 +2칸, 틀려도 감점 없음), 지름길, 혼잡
- 틀리면 반송, 신뢰도 −1(5칸). 해설을 보고 그 자리에서 고친다
- 다 돌면 관문마다 소포 주소를 기록한 "여행 기록" 표가 나온다

## 스테이지

1. 집 안 택배: 127.0.0.1:8000(FastAPI)과 :5432(DB). loopback이라 이더넷 봉투 없음 (W2-3)
2. 동네 밖으로: 같은 /24 프린터는 직접, 웹 서버는 Gateway MAC으로 (W2-4)
3. 스티커 릴레이: 라우터 3개, 홉마다 MAC 교체·TTL −1, IP는 그대로 (W2-5)
4. 공유기의 장부: 세 기기가 공인 IP 하나로. NAT 장부로 답장 세 통 분배 (W2-6)
5. 패킷 월드 투어: 포장부터 귀가까지 종합

## 조작

클릭. 단축키: Space 주사위, Enter 봉인/계속, 1~4 선택, Esc 선택 해제.
