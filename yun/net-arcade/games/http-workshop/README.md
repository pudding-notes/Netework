# HTTP 공방 & 보안 검문소

상태: 플레이 가능

- 주차: Week 4 (+ Week 2)
- 원형: 조립 퍼즐 + 서류 심사 (Papers, Please), 턴제
- Quick Check: W4-4, W4-5, W4-7, W4-8, W4-9, W2-7

## 진행

스테이지마다 의뢰서가 몇 장 쌓여 있다. 틀리면 신뢰도 −1(5칸), 해설을 보고 그 자리에서 다시. 남은 신뢰도로 별을 준다.

과제 유형

- 조립: 블록을 끌어다 놓아(드래그 앤 드롭, 클릭도 가능) HTTP 메시지를 만든다 (시작줄 → 헤더 → 빈 줄 → 본문). 놓은 줄은 끌어서 순서를 바꾸거나 상자로 끌어 뺀다. 함정 블록 포함
- 줄 고르기: 원문에서 헤더가 끝나는 줄, 두 번째 응답이 시작되는 줄을 고른다
- 상황 판단: 응답이 사라진 요청을 다시 보내도 되는가. 서버 장부가 결과(중복 주문 등)를 보여 준다
- 여러 개 고르기: 덩달아 기다리는 스트림, 서버에 접속할 수 있는 사람
- 분류: 도청자 시점에서 보인다 / 암호화
- 인증서 심사: 통과 또는 거부 사유(도메인, 유효기간, 신뢰 체인, 폐기)

## 스테이지

1. 메시지 조립 공방: 빈 줄 = 헤더 끝, Content-Length = 본문 끝 (W4-4)
2. 두 번 들어온 주문: GET·PUT·DELETE는 멱등, POST는 멱등 키, "더하기" PATCH는 위험 (W4-5)
3. 창구가 몇 개?: HTTP/1.1의 HTTP 계층 HOL, HTTP/2의 TCP 계층 HOL, HTTP/3(QUIC)의 스트림 독립 (W4-7)
4. 도청자의 망원경: HTTPS에서 보이는 것(IP·포트·DNS·SNI·크기)과 암호화되는 것 (W4-8)
5. 인증서 검문소: SAN·와일드카드, 만료·시작 전, 자체 서명, 폐기, 검사 항목이 아닌 정보 (W4-9)
6. 열린 문, 닫힌 문: 127.0.0.1 / 0.0.0.0 bind, 포트포워딩, 방화벽, 보안 그룹 (W2-7)

클릭. 단축키: Enter 제출/다음, 1~9 블록·보기·선택.
