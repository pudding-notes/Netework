# 패킷 닌자

상태: 플레이 가능

- 주차: Week 2~4 (IP·CIDR, 포트, 프로토콜) + 방화벽 규칙
- 원형: 과일닌자 (실시간, 무한 모드)
- Quick Check: W2-7 (외부 공개 여부는 방화벽·NAT·Security Group이 정한다)

## 플레이

- 패킷이 아래에서 튀어 오른다. 패킷에는 프로토콜(TCP/UDP/ICMP), 목적지 포트, 출발지 IP가 적혀 있다.
- 오른쪽 방화벽 규칙을 위에서부터 읽어 처음 맞는 줄이 정답이다(실제 ACL처럼 first match).
- 차단(DENY)이면 마우스로 벤다(드래그, 클릭도 된다). 허용(ALLOW)이면 그냥 떨어지게 두어 내부 서버로 보낸다.
- 정상 패킷을 베거나(정상 트래픽 차단) 차단 대상을 놓치면(침입 허용) 신뢰도 −1. 5칸이 바닥나면 끝.
- 틀리면 오른쪽에 그 패킷이 몇 번 규칙에 처음 걸렸는지, CIDR 범위 안/밖인지 해설이 나오고 해당 규칙 줄이 깜빡인다.
- ⏳ 보라 구슬을 베면 5초 슬로모.

## 규칙 개정 (무한)

패킷 15개마다 규칙이 무작위로 새로 만들어진다. 개정 때마다 게임이 멈추고 새 규칙을 읽을 시간을 준다.

- 1~2번째: 기본 허용 + 차단 목록 (Telnet/SMB/RDP 포트, 나쁜 /24 대역, UDP나 ICMP 전체)
- 3~4번째: 기본 차단 + 허용 목록 (HTTP·HTTPS, DNS, ping, SMTP). 4번째부터 맨 위에 나쁜 대역 차단이 붙기도 한다
- 5번째부터: 예외가 있는 순서 규칙. 예) 사내망(10/8 등)에서 오는 SSH만 허용 → 나머지 SSH 차단 → 웹 허용 → 기본
- 7번째부터: 차단 대역이 /22, /20처럼 옥텟 경계가 아닌 CIDR로 나온다

패킷은 규칙 하나를 노려 만들되, 30%는 대역 경계 바로 밖 주소로 만들어 아슬아슬하게 비껴가게 한다. 정답은 항상 규칙을 처음부터 다시 평가해서 정한다.

패킷은 화면 위쪽 15~25% 높이까지 올라가고, 처음에는 한 개가 보이는 시간이 약 5초다. 속도는 처음 0.5배에서 규칙이 바뀔수록 조금씩 빨라진다(최대 0.85배). 새 규칙의 처음 패킷 3개는 하나씩 천천히 나온다.

규칙은 오른쪽 위 노란 테두리 패널에 크게 표시된다(차단 줄은 붉게, 허용 줄은 초록으로). 새 규칙이 시작되면 패널이 몇 번 깜빡인다. Esc나 Space로 멈추면 규칙 표가 화면 가운데에 크게 뜬다.

## 조작

마우스 드래그 또는 클릭으로 베기 · `Esc`/`Space` 일시정지(규칙 크게 보기, 탭을 벗어나도 자동 정지)
