# 패킷 솔리테어

상태: 플레이 가능

- 주차: Week 3
- 원형: 카드 솔리테어 (턴제, 시간 제한 없음)
- Quick Check: W3-7 (중복 ACK의 의미), W3-6 (흐름 제어가 보호하는 대상)

## 비유

세그먼트 = 카드(seq = 첫 바이트, len = 바이트 수). 정리 칸 = 앱에 순서대로 넘기는 곳. 버퍼 = 수신 버퍼. 딜러 = 송신자. 선로 = 네트워크.

## 핵심 플레이

카드가 한 장씩 도착하면

1. 놓기: 정리 칸(바로 이어지는 카드만) / 버퍼(앞에 빠진 바이트가 있는 카드) / 버림(중복 카드)
2. ACK: 다음에 필요한 바이트 번호를 골라 딜러에게 보낸다

딜러는 중복 ACK를 3개 받으면(같은 번호가 3번 더) 빠진 카드를 빠른 재전송한다. ACK에 진전이 7턴 동안 없으면 타임아웃 재전송. 받지 않은 데이터를 ACK하면 거짓 ACK(신뢰도 −1).

## 스테이지

1. 정리 칸 기초: 선배 따라하기 튜토리얼. 순서 뒤바뀜, 누적 ACK
2. 사라진 카드: 유실 → 중복 ACK → 빠른 재전송, 중복 도착 카드 버리기
3. 길이가 제각각: 카드에 범위가 없다. seq + len 계산
4. 좁은 손: 버퍼 3칸, 앱이 바쁜 구간, rwnd와 창고 업데이트 ACK
