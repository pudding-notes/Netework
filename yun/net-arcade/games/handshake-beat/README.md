# 핸드셰이크 비트

상태: 플레이 가능

- 주차: Week 3 (TCP 연결 맺기·끊기, 상태 전이)
- 원형: 리듬게임 (실시간, 무한 모드)
- Quick Check: W3-1 (3-way handshake), W3-8 (TIME_WAIT·CLOSE_WAIT)

## 플레이

- 상대가 보낸 패킷(흰 노트)과 내 앱의 호출(노란 노트: connect(), close(), read()=0)이 오른쪽에서 흘러온다.
- 노트가 노란 판정선에 닿을 때 내 소켓이 보낼 답을 누른다.
  - `S` SYN · `D` SYN+ACK · `F` ACK · `J` FIN · `K` RST · `Space` 안 보냄 (화면 버튼도 된다)
- 판정: 맞는 키를 ±0.11초 안에 누르면 PERFECT, ±0.32초 안이면 GOOD. 틀린 키는 WRONG, 놓치면 MISS(게이지 −18).
- "안 보냄"이 정답인 노트(ACK·RST 받음 등)는 가만히 있어도 OK로 넘어간다.
- 위에 내 소켓 상태가 크게 보이고, 판정 뒤에는 아래에 "어느 상태에서 무엇을 받아 무엇을 보내고 어디로 가는지" 해설이 나온다.

## 연결(세션)마다 무작위

- 역할: 서버와 클라이언트가 번갈아 나온다.
- 종료 방식: 상대가 먼저 닫음(CLOSE_WAIT → LAST_ACK), 내가 먼저 닫음(FIN_WAIT_1 → FIN_WAIT_2 → TIME_WAIT), 상대 RST.
- 사건(레벨이 오르면 섞임): 닫힌 포트로 온 SYN(RST로 거절), LISTEN에 온 연결 없는 ACK(RST), SYN에 RST로 답이 옴(Connection refused), 같은 데이터 재전송(다시 ACK), CLOSE_WAIT에서 read()=0, TIME_WAIT 중 FIN 재전송(다시 ACK).
- 데이터 노트의 seq·len·ack 숫자도 매번 다르다.

## 속도

BPM 72에서 시작해 연결마다 +5(최대 126). 노트는 판정선까지 약 4.6초 동안 보이고(최소 2.6초), 노트 사이는 최소 150px 떨어진다. 4번째 연결부터 1박 간격이 섞인다.
