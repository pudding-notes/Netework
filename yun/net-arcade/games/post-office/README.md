# 우체국 분류소

상태: 플레이 가능

- 주차: Week 2
- 원형: Papers, Please (시간 제한 없는 턴제)
- Quick Check: W2-1 (같은 subnet?), W2-2 (broadcast·host 수), W2-4 (Default Gateway)

## 비유

IP 주소 = 동네 번호(네트워크 부분) + 집 번지(호스트 부분). 마스크는 어디까지가 동네 번호인지 긋는 자. 큰 우체국 = Default Gateway.

## 핵심 플레이

편지의 받는 주소를 보고 도장을 찍는다.

- 직접 배달: 같은 서브넷
- 큰 우체국으로: 다른 서브넷 → Default Gateway
- 동네 방송: 우리 서브넷의 브로드캐스트 주소

도구 두 가지 (사용해도 감점 없음)

- 비트 확대경: ① 이진수로 펼치기 → ② 마스크 씌우기(AND) → ③ 동네 번호 비교
- 동네 지도: 동네 번호가 끝나는 덩어리를 블록 단위로 보여 줌

도장을 찍으면 AND 계산식과 의미(ARP로 직접 / Gateway에 맡김 / 브로드캐스트)가 해설 카드로 나온다.

## 스테이지 (하루 단위)

1. 첫 출근 /24 — 선배 따라하기 튜토리얼. 192.168.1.20 vs 192.168.2.20
2. 캠퍼스 /16 — 세 번째 숫자가 달라도 같은 동네. Gateway는 언제 필요한가
3. /26 쪼개진 동네 — 브로드캐스트 해금, 퇴근 전 정산
4. 이사 가는 날 /27 → /28 — 오전·오후 주소 변경, 정산
5. /22 덩어리 넘기 — 경계가 세 번째 덩어리 가운데

Day 3부터 확대경이 비교 판정을 해 주지 않는다. "판정 힌트" 체크로 다시 켤 수 있다.

## 무한 모드: 무한 근무

- 스테이지 목록 맨 끝의 ∞ 버튼, 또는 허브의 "∞ 무한 모드" 탭에서 바로 시작.
- 편지 6통마다 우체국이 이사한다. 이사할수록 프리픽스가 어려워진다: 1번째 동네 /24·/16 → 2번째 /24·/16·/25·/26 → 3번째 /25~/28 → 4번째부터 /20~/30.
- 주소(10/8, 172.16/12, 192.168/16 대역)와 편지 목적지는 매번 무작위. 경계 바로 앞뒤 번지, 끝 번호만 같은 다른 동네 같은 함정이 섞인다.
- 두 번째 동네부터 동네 방송 도장과 이사 전 정산 문제 1개.
- 점수: 바른 도장 100 + 20 × (동네 번호 − 1). 판정 힌트를 켜고 찍으면 기본 점수 절반. 정산 정답 150.
- 신뢰도 5칸이 바닥나면 끝. ★는 이사 1/4/8번에서.
