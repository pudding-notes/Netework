# 프로토콜 산성비

상태: 플레이 가능

- 주차: Week 1~4 복습 + Week 1~5 약어
- 원형: 한컴타자 산성비 (실시간, 무한 모드)
- Quick Check: 직접 매핑 없음. 1~4주차 개념을 짧은 답으로 반복 연습한다.

## 플레이

- 하늘에서 문제 카드가 떨어진다. 답을 치고 Enter를 누르면 그 카드가 사라진다.
- 카드가 바닥에 닿으면 지반 ♥ −1. 5칸이 다 녹을 때까지 끝나지 않는다.
- 틀린 입력은 감점 없이 콤보만 끊긴다.
- 8문제마다 LEVEL이 오른다. LEVEL 3부터 계산 문제(서브넷 호스트 수, 마스크, seq/ack, 대역폭), LEVEL 5부터 어려운 계산(네트워크·브로드캐스트 주소, cwnd, DNS TTL)이 섞인다. 계산 문제는 천천히 떨어진다.
- 금테 카드는 아이템: ☂ 화면 정리, ❄ 4초 멈춤, ❤ 지반 회복.
- 바닥에 닿은 문제는 오른쪽 오답 노트에 정답과 해설이 남고, 끝나면 자주 놓친 유형을 보여 준다.
- Esc 일시정지(문제는 가려진다). 탭을 벗어나면 자동 일시정지.

## 모드

전체 혼합, 1주차 집중, 2주차 집중, 3주차 집중, 4주차 집중, 약어 → 풀네임, 풀네임 → 약어. 모드별 최고 점수를 저장한다.

## 약어 모드

- 데이터: `abbr.js`. 네트워크 시각노트의 중간 대비 약어 목록(용어표 Week 1-2·3·4·5) 중 실제 약어가 아닌 항목(AAAA, TXT, JS, DB, UI, AI, gRPC 등)을 뺀 134개. 우리말 이름은 용어표 본문에서 가져왔다(일부만).
- 약어 → 풀네임: `CORS`가 떨어지면 `Cross-Origin Resource Sharing`을 친다.
  - 띄어쓰기 · 대소문자 · 하이픈 · 괄호 설명 · 끝의 s는 무시한다(시각노트 약어 드릴과 같은 기준). `cross origin resource sharing`도 정답.
  - 풀네임 안의 약어를 풀어 써도 정답이다. 예) SRTT → `Smoothed RTT` 또는 `Smoothed Round-Trip Time`.
  - 철자 변형도 인정: Acknowledgment/Acknowledgement, Media/Medium Access Control 등.
  - 이름이 길수록 천천히 떨어지고, 화면에 동시에 최대 5개까지만 내린다.
  - LEVEL 1~2는 24자 이하, LEVEL 3~4는 34자 이하, LEVEL 5부터 가장 긴 이름(HATEOAS 등)까지 나온다.
  - 한 바퀴(모든 약어)를 다 낼 때까지 같은 약어를 다시 내지 않는다.
- 풀네임 → 약어: 반대 방향 몸풀기. 이 모드는 HTTP/HTTPS 구분을 위해 끝의 s를 무시하지 않는다.
- 바닥에 닿으면 오답 노트에 정답 풀네임과 우리말 이름이 남는다.

## 암기 방지

문제는 생성기가 매번 새로 만든다. IP 주소, 프리픽스 길이, seq 번호, 바이트 수, TTL, 파일 크기·회선 속도 등이 무작위다. 용어 문제(플래그, 소켓 호출, 상태, 레코드 종류)는 목록에서 고르지만 순서와 섞이는 문제가 매번 다르다.

## 입력

- 대소문자, 공백, `_ - + . /` 는 무시한다. `SYN+ACK`, `synack`, `close_wait`, `closewait` 모두 인정.
- 한글 두벌식 상태로 친 영어도 인정한다. `ㅅ체` → `tcp`, `뇨ㅜ` → `syn`.
- O/X 문제는 `o`/`x`, `예`/`아니오` 등.

## 단순화

- 혼잡 제어 문제의 cwnd는 MSS 단위로 센다.
- 광섬유 RTT 문제는 빛의 속도(약 200km/ms)만 계산한다. 실제로는 경로가 더 길고 장비 지연이 더해진다.
