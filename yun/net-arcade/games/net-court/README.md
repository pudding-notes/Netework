# 네트워크 역전재판

상태: 플레이 가능

- 주차: Week 3·4
- 원형: 역전재판 (증거 제시 추리), 턴제
- Quick Check: W3-9, W3-10, W4-6, W4-10

## 진행

1. **조사**: 터미널 명령(curl, ping, tcpdump, ss, nslookup, DevTools Timing 등)을 실행한다. 결과 속 핵심이 법정 기록에 증거로 들어간다. 핵심 증거를 모두 모으면 법정으로 간다.
2. **심문**: 증언을 ◀ ▶로 넘기며 **잠깐!**(추궁)으로 단서를 얻는다. 증거와 모순되는 증언에서 증거를 골라 **이의 있음!**
3. **지목**: 진짜 원인과 고칠 방법을 고른다.

틀린 증거·틀린 지목은 재판장 신뢰 -1(5칸). 모두 잃으면 패소. 남은 신뢰로 별을 준다.

## 사건

|---|---|---|---|
| 1 | 거절당한 접속 (튜토리얼) | refused = 서버까지 갔지만 그 포트에 listen 없음 → RST | W3-9 |
| 2 | 침묵하는 DB | timeout = 보안 그룹이 /24 밖의 SYN을 응답 없이 DROP. ping 불가 ≠ 서버 다운 | W3-9 |
| 3 | 느림보 다운로드 | 측정부터: RTT 정상, 처리량 8Mbps, 재전송·cwnd, CRC 오류 → 불량 케이블 | W3-10 |
| 4 | 두 개의 오류 화면 | 404는 원본 앱, 502는 nginx가 만듦. 502의 원인은 죽은 업스트림 | W4-6 |
