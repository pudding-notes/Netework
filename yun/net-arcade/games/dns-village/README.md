# DNS 마을 탐험

상태: 플레이 가능

- 주차: Week 4
- 원형: 지도 이동 RPG (NPC 대화), 턴제
- Quick Check: W4-1, W4-2, W4-3

## 비유

나 = 리졸버. 의뢰인의 집 = 브라우저·OS(stub). 장로의 언덕 = 루트 서버. com·net·kr 마을 = TLD 서버. example.com 집·inu.ac.kr 본부 = 권한 서버. 수첩 = 캐시(🏷️ A 주소, 📍 NS 위치, 남은 TTL). 마을 시계는 이동 1번에 1분.

## 핵심 플레이

- 의뢰인이 이름을 맡긴다(재귀 질의). 사무소에서 수첩을 확인하고, 없으면 지도에서 마을을 눌러 찾아간다
- 장로·촌장은 "저기 가 보게"(반복 응답, 위임)만 알려 준다. 위치를 알게 된 마을만 안개가 걷혀 갈 수 있다
- 권한 서버가 최종 답(A)과 TTL을 준다. 의뢰인의 집에 가져가면 조회 완료
- 엉뚱한 마을(이름과 상관없는 TLD 등)에 가면 신뢰도 −1. 3·4스테이지는 헛걸음(수첩으로 충분한데 장로부터 다시)도 −1
- URL 자르기: URL 조각을 끌어다 "DNS에게 / 서버에게 / 브라우저만" 상자에 넣는다

## 스테이지

1. 주소 자르기 (튜토리얼): URL 중 DNS가 아는 건 host뿐. 선배와 첫 조회 (W4-1)
2. 길 묻기: 재귀(의뢰인 → 리졸버) vs 반복(리졸버 → root·TLD·권한) (W4-2)
3. 수첩 활용: A·NS 캐시와 TTL 만료, 장로 건너뛰기 (W4-3)
4. 이사 간 집 사건: 레코드를 바꿔도 TTL 동안 옛 주소가 쓰인다. TTL 미리 낮추기, 브라우저·OS·리졸버 세 겹 캐시 (W4-3)

## 조작

마을 클릭 이동, 대화는 클릭 또는 Enter, 1~3 보기, C 수첩의 답 쓰기.
