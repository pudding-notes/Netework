# 혼잡 제어 블랙잭

상태: 플레이 가능

- 주차: Week 3 (+ Week 1)
- 원형: 블랙잭 (턴제, 시간 제한 없음, 카지노 연출)
- Quick Check: W3-6 (혼잡 제어 vs 흐름 제어), W3-2 (UDP가 빠르다?), W1-1 (대역폭 vs 지연)

## 비유

라운드 = 한 RTT, 베팅 = cwnd(이번 RTT에 보내는 패킷 수), 카드 = 패킷, 숨은 한도 = 병목 파이프(BDP) + 라우터 큐, BUST = 큐가 넘쳐 패킷 손실.

## 핵심 플레이

- DOUBLE ×2: 슬로 스타트 (cwnd < ssthresh일 때만)
- HIT +1: 혼잡 회피
- STAND: 그대로 (지연이 늘 때 멈추는 지연 기반 전략)

카드를 걸면 딜 → 뒤집기 → 결과. 파이프까지는 ✓, 큐에서 기다리면 ⏳(RTT 증가, 콤보 정지), 넘치면 ✗(BUST: cwnd 반토막, ssthresh = 그 값). 한도의 두 배를 넘기면 타임아웃(cwnd 1부터). 큐 없이 파이프를 딱 채우면 PERFECT PIPE 잭팟, 손실 없이 이어 가면 콤보 배율 ×3까지. 처음 겪는 사건(BUST, 타임아웃, 큐, PERFECT, rwnd 제한, handshake)마다 멈추고 해설 카드가 뜬다.

## 테이블

1. 슬로 스타트 테이블: 1장에서 두 배씩, 첫 BUST와 곱셈 감소
2. AIMD 톱니: 다른 사용자 때문에 파이프가 줄었다 늘었다, cwnd 톱니 차트
3. 수신자가 막는다: 공개된 rwnd 카드, 실제 전송 = min(cwnd, rwnd)
4. UDP 난입: TCP는 handshake 1라운드, UDP는 연결 없이 매 라운드 20장 고정
5. 해외 테이블: 같은 대역폭, RTT 150ms(5배) → 파이프(BDP)도 5배인 200장, 걸린 시간 비교

## 무한 모드: 무한 카지노

- 스테이지 목록 맨 끝의 ∞ 버튼, 또는 허브의 "∞ 무한 모드" 탭에서 바로 시작.
- 테이블마다 조건이 무작위: RTT(20~150ms, 파이프 크기가 RTT에 비례), 파이프·큐 크기, 중간에 사용자가 들고 나며 파이프가 바뀜, 처음부터 정해진 ssthresh, 수신자 rwnd 또는 UDP 난입(한 테이블에 둘 중 하나). 테이블이 올라갈수록 조건이 많이 섞인다.
- 목표 칩 = 같은 테이블을 정석(Reno: 문턱 전 DOUBLE, 이후 HIT)으로 했을 때의 칩 × (0.8에서 시작해 1.0까지). 그래서 항상 달성 가능하다. 큐가 차면 STAND하는 등 더 잘하면 넉넉히 넘는다.
- 테이블이 끝나면 숨어 있던 파이프·큐 크기와 정석 점수를 공개한다.
- 목표 미달 시 ♥ −1. ♥ 3개가 다 떨어지면 폐장. 점수는 누적 칩. ★는 통과 2/5/10테이블에서.
