# 주소 블록 퍼즐

상태: 플레이 가능

- 주차: Week 2
- 원형: 블록 블라스트 / 1010! (턴제, 시간 제한 없음)
- Quick Check: W2-2 (브로드캐스트 주소와 사용 가능한 호스트 수)

## 핵심 플레이

16×16 주소판에 서브넷 블록을 놓는다.

1. 요청서의 호스트 수를 보고 블록 크기(프리픽스)를 고른다. 호스트 수 = 2^(32 − p) − 2. 너무 작으면 거절, 더 작게 가능하면 경고
2. 주소판에 놓는다. 블록은 자기 크기의 배수 번지에서만 시작한다. 고르면 놓을 수 있는 시작 칸에 노란 점이 찍히고, 마우스를 올리면 초록(가능)·빨강(불가)으로 미리 보인다
3. 놓은 블록에 대한 퀴즈 하나(브로드캐스트, 호스트 수, 첫/마지막 호스트). 답하면 네트워크 주소·브로드캐스트·호스트 범위가 정리된다

틀려도 실패하지 않는다. 실수와 퀴즈 결과로 별이 정해진다. 되돌리기(U) 가능.

## 스테이지

1. 블록 크기 익히기: 192.168.10.0/24, 선배 따라하기
2. 빈자리 찾기: 기존 블록 사이의 경계 맞는 빈자리, /30 라우터 링크
3. 빈틈없이 채우기: 요청 7개 = 정확히 256칸, 요청 순서를 직접 고른다
4. VPC 설계: 10.0.0.0/16, 한 칸 = /24, 가용 영역 두 곳에 서브넷 짝짓기

## 조작

클릭. 단축키: 1~6 블록 크기, U 되돌리기, 1~3 퀴즈, Enter 다음.
